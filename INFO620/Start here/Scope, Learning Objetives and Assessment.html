INFO620
 Course Overview

Scope, Learning Objectives, and Assessment

| Course Scope

This course is a formal study of enterprise database system theories, models, design, and practical applications of database systems. We will use Oracle by example to illustrate the model for practical purposes.

| Course & Learning Objectives

Select each Course Objective to see the associated Learning Objectives and Assessments.

Learning Objectives

  • LO-1.1: Identify DBMS components, processing layers, and architecture types.
  • LO-1.2: Explain administrative responsibilities and performance considerations.
  • LO-1.3: Analyze the role of the database administrator in supporting performance, reliability, and security.

Assessments

  • Week 1 - Discussion: Enterprise Database Architecture in the Real World
  • Week 1 - Assignment: Enterprise DBMS Architecture & Analysis

Learning Objectives

  • LO-2.1: Identify entities, attributes, and relationships from a narrative business case.
  • LO-2.2: Construct ER and EER diagrams that correctly represent cardinality and participation constraints.
  • LO-2.3: Design UML class diagrams that align with ER/EER models for the same problem domain.
  • LO-2.4: Evaluate alternative conceptual models fro completeness and correctness against business requirements.

Assessments

  • Week 2 - Assignment: ER/EER Modeling & UML
  • Week 2 - Assignment: Project Topic Selection

Learning Objectives

  • LO-3.1: Define key relational concepts, including relation, attribute, tuple, schema, and key.
  • LO-3.2: Apply domain, key, entity integrity, and referential integrity constraints to relational schemas.
  • LO-3.3: Identify update anomalies in poorly structured relations.
  • LO-3.4: Construct relational algebra expressions (e.g., selection, projection, join, union) to answer specific query questions.

Assessments

  • Week 3 - Discussion: Relational Constraints, Anomalies, and Algebra in Action
  • Week 3 - Assignment: Relational Schemas & Relational Algebra

Learning Objectives

  • LO-4.1: Identify functional dependencies from given relational data and business rules.
  • LO-4.2: Deconstruct relations into 1NF, 2NF, 3NF, and BCNF using normalization rules.
  • LO-4.3: Evaluate the quality of relational designs based on redundancy, anomaly risk, and dependency preservation.
  • LO-4.4: Recommend an appropriate level of normalization for a given use cause, justifying trade-offs between performance and data integrity.

Assessments

  • Week 4 - Assignment: Functional Dependencies & Normalization to BCNF
  • Week 4 - Assignment: Project Annotated Bibliography

Learning Objectives

  • LO-5.1: Interpret existing use case, sequence, collaboration, and activity diagrams in the context of database usage scenarios.
  • LO-5.2: Develop use case diagrams that clearly capture system actors and their interactions with database-related functions.
  • LO-5.3: Construct UML sequence or collaboration diagrams that model the flow of data-related operations across system components.
  • LO-5.4: Analyze behavioral models to identify potential performance or security concerns in database interactions.

Assessments

  • Week 5 - Assignment: UML Behavioral Modeling
  • Week 5 - Assignment: Project Outline

Learning Objectives

  • LO-6.1: Describe common database security threats, including SQL injection, privilege abuse, and misconfiguration.
  • LO-6.2: Compare discretionary, mandatory, and role-based access control models in terms of strengths and limitations.
  • LO-6.3: Design a role and privilege scheme for a small enterprise database scenario.
  • LO-6.4: Evaluate the effectiveness of security controls such as encryption, auditing, and authentication in a given case study.

Assessments

  • Week 6 - Discussion: Security Breakdown in a Mid-Sized Company
  • Week 6 - Assignment: SQL Security, Roles, Threat Analysis

Learning Objectives

  • LO-7.1: Explain the key components of data warehouse architecture, including staging, integration, and presentation layers.
  • LO-7.2: Design a simple star schema with fact and dimension tables for a define analytical need.
  • LO-7.3: Differentiate between OLAP operations such as roll-up, drill-down, slice, and dice using concrete examples.
  • LO-7.4: Assess technology and implementation considerations (e.g., performance, storage, refresh strategy) for a data warehousing solution,

Assessments

  • Week 7 - Discussion: Designing a Data Warehouse for a Subscription Service
  • Week 7 - Assignment: Final Project Paper

Learning Objectives

  • LO-8.1: Summarize the defining characteristics and requirements of mobile, multimedia, GIS, and genomic database systems.
  • LO-8.2: Compare specialized database architectures to traditional relational systems with respect to data models, indexing, and query support.
  • LO-8.3: Evaluate which specialized database approach is most appropriate for a given real-world scenario.

Assessments

  • Week 8 - Discussion: Choosing the Right Specialized Database for Real-World Problem
  • Week 8 - Assignment: Specialized Databases & Prototype Queries

| Program Learning Outcomes

Program Learning Outcomes (PLO) serve as a roadmap for educational success and guide the courses that you take. 

This course supports the following PLOs:

  • Apply key management theory, principles, best practices, tools, and technologies associated with information systems.
  • Utilize graduate level critical thinking, reasoning, and writing to defend the logic and the conclusions in scholarly research.
  • Assess the vulnerabilities of information systems with respect to security and the methodologies to mitigate this risk.
