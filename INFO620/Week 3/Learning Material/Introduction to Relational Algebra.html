Week 3 Relational Theory, Constraints, and Relational Algebra

Introduction to Relational Algebra

Relational algebra provides the mathematical foundation for querying relational databases. Before SQL, relational algebra served as the primary mechanism for manipulating data. Today, SQL is essentially a declarative implementation of relational algebra concepts.

The primary relational algebra operations include the following:

  1. Selection (σ)
    Extracts rows meeting a condition.
    Example: σ(Customer.City = 'Dallas')(Customer)
  2. Projection (π)
    Extracts specific columns.
    Example: π(FirstName, LastName)(Customer)
  3. Union (∪)
    Combines tuples from two compatible relations.
  4. Set difference (−)
    Returns tuples present in one relation but not another.
  5. Cartesian product (×)
    Forms pairs of tuples by combining all rows from two relations.
  6. Join (⨝)
    Combines relations based on related attributes.

There are multiple types of joins:

  • Natural join
  • Inner join
  • Outer join (left, right, full)

Join operations are fundamental to building complex queries in SQL.

Example Query (Algebra to SQL)

Relational Algebra:
σ(Customer.City='Dallas')(Customer) ⨝ Order

SQL Equivalent:
SELECT *
FROM Customer
JOIN Order ON Customer.CustomerID = Order.CustomerID
WHERE Customer.City = 'Dallas';

This direct mapping supports the transition you will make to SQL in later weeks.
