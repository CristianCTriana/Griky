Week 4 Functional Dependencies and Normalization

The First Normal Form (1NF) and Eliminating Repeating Groups

Normalization involves decomposing relations through progressively restrictive normal forms. The first step is transforming data structures to satisfy first normal form (1NF) requirements.

Requirements for 1NF

A relation is in 1NF if

  • All cell values are atomic (indivisible),
  • There are no repeating groups or arrays, and
  • Each tuple is unique.

Example of Nonatomic Data

An attribute such as PhoneNumbers = {555-1234, 555-6789} violates 1NF.

Corrected 1NF Structure

Create a separate relation:

CustomerPhone(CustomerID, PhoneNumber)

Eliminating Repeating Groups

Consider the following relation:

Order(OrderID, CustomerID, ProductList)

ProductList = (ProductA, ProductB, ProductC)

This violates 1NF.
Solution:
OrderLine(OrderID, ProductID, Quantity)

Why 1NF Matters

1NF is foundational for avoiding structural inconsistencies that complicate indexing, querying, and updates. Without 1NF, relational algebra and SQL cannot operate effectively (Khurana, 2024).

Example Case: Student Enrollment

A Student record contains the following:
CoursesEnrolled = {IN302, IN315, IN425}
This must be decomposed into a StudentCourse relation.

Understanding 1NF ensures that later normal forms can be applied correctly.
