Week 6 Database Security and Authorization

Authentication, Encryption, and Secure Communications

Beyond authorization, strong database security requires robust authentication and secure communication channels.

Authentication verifies identity before granting access. There are several kinds of authentication:

Password Authentication

Password authentication is the most common, but also the weakest if not combined with the following:

  • Password complexity enforcement
  • Hashing and salting
  • Multifactor authentication (MFA)

Token-Based Authentication

Tokens in token-based authentication include API keys, OAuth tokens, and digital certificates.

Kerberos

Kerberos is used in enterprise networks for secure ticket-based authentication.

Encryption protects data both in transit and at rest.

Data-at-Rest Encryption

Data-at-rest encryption blindly encrypts entire files, disks, or tablespaces.
This prevents access even if a file is stolen.

Column-Level Encryption

Column-level encryption encrypts sensitive attributes such as the following:

SSNs Credit card numbers Passwords

Hashing and Salting

Hashes protect passwords, whereas salts prevent rainbow-table attacks.

Transparent Data Encryption (TDE)

TDE automatically encrypts/decrypts data at the storage level without changing applications.

Best practices for securing network communications include the following:

  • Using TLS/SSL for all database connections
  • Limiting database access to specific IP ranges
  • Protecting API endpoints with firewalls and gateways
  • Disabling plain-text connections
