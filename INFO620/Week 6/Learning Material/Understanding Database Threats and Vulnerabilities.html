Week 6 Database Security and Authorization

Understanding Database Threats and Vulnerabilities

Database systems face a broad range of threats, many of which stem from predictable weaknesses that attackers exploit. Khurana (2024) highlights that database breaches often arise from misconfigurations, poor access control, and insecure application practices.

Common Threats

SQL injection occurs when malicious input is inserted into SQL commands. For example:

' OR '1'='1' --

This manipulation can bypass authentication, extract data, or modify records.

Privilege abuse occurs when users with legitimate access exceed their intended permissions.
This is the most common insider threat.

Malware and ransomware attacks encrypt or steal data, often targeting high-value enterprise systems.

Open ports, default credentials, or lack of encryption can allow unauthorized access in misconfigured databases.

Backups often contain sensitive full-database copies. If unencrypted, these backups can pose severe risks.

Vulnerability Points

Vulnerabilities fall into several categories:

  • Authentication weaknesses: Simple passwords, no MFA
  • Authorization gaps: Broad privileges, no least-privilege model
  • Insecure network endpoints: Unencrypted traffic
  • Insufficient monitoring: No auditing or anomaly detection
  • Weak application controls: Unsanitized inputs, no parameterized queries

Understanding vulnerabilities helps practitioners design strong defensive strategies.
