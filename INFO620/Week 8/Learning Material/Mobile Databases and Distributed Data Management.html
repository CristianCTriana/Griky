Week 8 Advanced Database Applications

Mobile Databases and Distributed Data Management

Mobile databases support applications where data must be accessed, updated, or synchronized across mobile devices, edge environments, and intermittently connected systems. The rise of smartphones, IoT devices, and real-time analytics has made mobile data management essential in modern computing (Khurana, 2024).

a. Intermittent Connectivity

Mobile users often lose or regain connectivity, requiring:

Offline data access Deferred updates Conflict resolution upon reconnection

b. Replication & Synchronization

Mobile DBMSs maintain replicas of data and must reconcile inconsistencies.
Common techniques include:

  • Timestamp-based methods
  • Version vectors
  • Conflict detection & merging rules

c. Lightweight Storage

Mobile devices require:

  • Embedded databases (SQLite)
  • Low footprint storage engines
  • Minimal processing overhead
  • Energy-efficient operations
  • Limited memory and battery
  • Unpredictable network latency
  • Security vulnerabilities on user devices
  • Ensuring ACID properties in disconnected mode

Despite these challenges, mobile databases power messaging apps, mobile commerce, vehicle navigation systems, and field service applications.
