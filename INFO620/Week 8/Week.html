What to Expect in Week 8

This module provides an introductory overview of advanced database systems, essential for understanding the evolving landscape of data management. As organizations expand their capabilities and data needs, traditional relational databases are increasingly insufficient. Enterprises are progressively dependent on specialized database systems tailored to handle diverse data formats, access patterns, and storage requirements. Week 8 introduces students to mobile databases, multimedia systems, geographic information systems (GIS), and genomic databases—each representing sophisticated solutions to contemporary data challenges. These systems go beyond classical database management system (DBMS) models, addressing issues related to performance, availability, scalability, and data types that traditional relational systems were not originally designed to support. This week functions as the culmination of the INFO620 course, synthesizing the conceptual, logical, and architectural lessons acquired during the program and demonstrating their application to real-world, domain-specific database challenges.

Objectives

CO-8: Appraise specialized database applications such as mobile, multimedia, GIS, and biological genome database systems. ▼
  • LO-8.1: Summarize the defining characteristics and requirements of mobile, multimedia, GIS, and genomic database systems.
  • LO-8.2: Compare specialized database architectures to traditional relational systems with respect to data models, indexing, and query support.
  • LO-8.3: Evaluate which specialized database approach is most appropriate for a given real-world scenario.
