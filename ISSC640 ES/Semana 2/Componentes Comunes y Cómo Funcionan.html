Fundamentos de Comunicación de Datos: LAN, MAN y WAN 

Componentes Comunes y Cómo Funcionan 

Toda red de área local, desde una pequeña configuración doméstica hasta una gran organización, está construida a partir de un conjunto de componentes esenciales. La siguiente tabla enumera estos componentes y sus funciones, y el video explica cómo trabajan juntos para conectar dispositivos y habilitar la transmisión de datos.

                                         
Componentes y Funciones de una LAN

Componente

Función
Dispositivos Finales (Hosts) Computadoras, laptops, teléfonos inteligentes, impresoras y servidores.
Tarjeta de Interfaz de Red (NIC) Un componente de hardware (generalmente integrado en el dispositivo final) que permite a un dispositivo conectarse a la red. La NIC suele ser parte de la tarjeta madre.
Medio de Red La vía física o inalámbrica para la transmisión de datos. Esto incluye cables Ethernet como CAT6 o CAT7.
Switch Un dispositivo central que conecta los dispositivos finales y dirige de manera inteligente los paquetes de datos dentro de una LAN. Los switches permiten múltiples conexiones simultáneas. El router se conecta al switch para proporcionar acceso compartido a la red.
Router Conecta la red de área local (LAN) a redes externas como Internet u otras redes remotas.
Protocolos TCP/IP y Ethernet son protocolos LAN de uso común. Ethernet opera en la capa de Enlace de Datos del modelo OSI, IP en la capa de Red y TCP en la capa de Transporte. El modelo OSI se abordará en la Semana 3 de este curso.
