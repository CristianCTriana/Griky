Semana 3
Protocolos de Red, Puertos y el Modelo OSI

Conclusión

Como aprendiste esta semana, los protocolos son las reglas que rigen el intercambio de datos a través de las redes, lo que permite que distintos dispositivos y sistemas se comuniquen de manera efectiva. En la capa de Transporte del modelo OSI, protocolos como TCP y UDP desempeñan un papel fundamental en la gestión de la entrega de datos. TCP proporciona una comunicación orientada a la conexión y confiable, con entrega garantizada, lo que lo hace adecuado para aplicaciones como la navegación web y el email. En contraste, UDP prioriza la velocidad sobre la confiabilidad, utilizando comunicación sin conexión para servicios como el streaming de medios y DNS. Estos protocolos de transporte se apoyan en números de puerto —identificadores lógicos que van del 0 al 65,535— para garantizar que los datos lleguen a la aplicación o servicio correcto, y muchos de los servicios de uso común operan dentro del rango de puertos más bajos. En conjunto, el modelo OSI ofrece un esquema estructurado que permite que los protocolos funcionen de manera consistente, proporcionando una base estandarizada para la comunicación a través de las redes.
