El Modelo de Interconexión de Sistemas Abiertos 

Además del conjunto de protocolos TCP/IP, también contamos con el modelo de Interconexión de Sistemas Abiertos (OSI), que es similar al conjunto de protocolos TCP/IP en cuanto a funcionalidad, con una diferencia importante. El modelo OSI no solo se ha utilizado para TCP/IP, sino también para muchos otros protocolos que no forman parte de la familia de protocolos TCP/IP.

Divide la compleja tarea de la comunicación en siete capas distintas, cada una con responsabilidades específicas. El propósito principal del modelo OSI es proporcionar un estándar universal para los protocolos de comunicación, ofreciendo un esquema para que sistemas informáticos, hardware y software de diferentes fabricantes puedan comunicarse de manera efectiva. En la década de 1980, muchos de los protocolos de comunicación eran propietarios.

Por ejemplo, IBM tenía su propio conjunto de protocolos, DEC hacía lo mismo, al igual que Novell. La Organización Internacional de Normalización (ISO) creó el modelo OSI con el fin de proporcionar este esquema y un estándar de protocolos para todos los fabricantes y protocolos de código abierto como TCP/IP.

Las siete capas del modelo OSI, junto con sus funciones y protocolos, se describen en la siguiente tabla. Los datos son creados por el usuario final en la capa de Aplicación. A medida que la Unidad de Datos de Protocolo (PDU) desciende por las diferentes capas, recopila los encabezados correspondientes a cada capa. Nótese que la PDU recibe nombres distintos en algunas de las capas.

Por ejemplo, en la Capa 4 (Transporte) se denomina Segmento, y en la Capa 3 (Red) se denomina Paquete. Cuando la PDU llega a la capa 1 (Física), se transforma en bits y se envía al destino. En el destino, la información recibida asciende desde la Capa 1 hasta la Capa de Aplicación (Capa 7). En cada capa, los encabezados correspondientes son eliminados y el resto de la PDU continúa hacia arriba. Por lo tanto, cada capa se comunica con la capa correspondiente en el destino utilizando los caracteres de control propios de esa capa específica.

Capas del Modelo OSI
Capa Función Principal Unidad de Datos (PDU) Protocolos/Ejemplos Comunes
Capa 7: Aplicación Proporciona la interfaz entre la aplicación del usuario y la red. Datos HTTP, FTP, SMTP, DNS
Capa 6: Presentación Gestiona el formato, la traducción, el cifrado y la compresión de datos. Datos JPEG, MPEG, SSL/TLS (cifrado)
Capa 5: Sesión Administra el inicio, mantenimiento y cierre de una sesión de comunicación. Datos NetBIOS, RPC
Capa 4: Transporte Proporciona entrega de datos confiable o no confiable y control de flujo. Segmento (TCP) / Datagrama (UDP) TCP, UDP
Capa 3: Red Gestiona el direccionamiento lógico (IP) y el enrutamiento de datos a través de diferentes redes. Paquete IP, ICMP, Router
Capa 2: Enlace de Datos Proporciona direccionamiento físico (MAC), detección de errores y sincronización de tramas en una red local. Trama Ethernet, dirección MAC, Switch
Capa 1: Física Transmite datos binarios sin procesar (bits) a través del medio físico. Bit Cables (Cobre, Fibra), Wi-Fi, Hub
