Protocolos de Red, Puertos y el Modelo OSI 

Suite de Protocolos TCP/IP 

TCP/IP es tan ampliamente utilizado que cuenta con su propia suite de protocolos. El propósito más fundamental de esta suite es descomponer la comunicación de red en piezas más pequeñas, manejables e independientes, denominadas capas. En cada capa se encuentran mapeados ciertos protocolos. Esto proporciona modularidad e información sobre cómo los protocolos trabajan en conjunto. La siguiente tabla identifica las capas de TCP/IP, junto con sus funciones y protocolos clave.

Suite de Protocolos TCP/IP
Capa TCP/IP Capas OSI Correspondientes Función Principal Protocolos Clave
Capa de Aplicación Aplicación, Presentación, Sesión Proporciona la interfaz para las aplicaciones del usuario final. Gestiona el formato de datos de alto nivel y la administración de sesiones. HTTP, HTTPS, SMTP, DNS, FTP, Telnet
Capa de Transporte Transporte Gestiona la transferencia de datos de extremo a extremo de manera confiable (TCP) o rápida/no confiable (UDP) entre procesos (aplicaciones). TCP, UDP
Capa de Internet Red Responsable del direccionamiento lógico (direcciones IP) y el enrutamiento de paquetes a través de diferentes redes. IP (IPv4, IPv6), ICMP, ARP
Capa de Acceso a la Red Enlace de Datos, Física Define cómo se transmiten físicamente los datos a través de tecnologías de red específicas (por ejemplo, fibra óptica, cobre, Wi-Fi) y gestiona las direcciones de hardware (MAC). Ethernet, Wi-Fi (802.11), PPP

El siguiente diagrama ilustra cómo se envía un correo electrónico utilizando el protocolo SMTP, que emplea otros protocolos como TCP e IP. El correo electrónico se origina en la capa de Aplicación de la suite de protocolos TCP/IP, fluye hacia abajo a través de las diferentes capas y recopila los encabezados necesarios. En la capa más baja, se transforma en bits y se envía a través de la red.

  • SMTP (Capa de Aplicación): Este protocolo gestiona el contenido del mensaje de correo electrónico.
  • TCP (Capa de Transporte): SMTP utiliza TCP para una entrega confiable y orientada a la conexión. TCP divide los datos de SMTP en segmentos y añade encabezados para la secuenciación y la verificación/corrección de errores.
  • IP (Capa de Internet): TCP entrega los segmentos a la Capa de Red, donde IP encapsula el segmento TCP completo (incluidos los datos de SMTP) en un paquete IP (o datagrama). IP añade las direcciones IP de origen y destino, que son esenciales para enrutar el paquete a través de Internet.
  • Entrega Física: El paquete IP se entrega entonces a las capas inferiores (Enlace de Datos y Física) para su transmisión a través de la red física.
