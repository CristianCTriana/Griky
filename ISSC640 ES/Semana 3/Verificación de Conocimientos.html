Semana 3
Protocolos de Red, Puertos y el Modelo OSI

Semana 3 - Verificación de Conocimientos

Pregunta 1: En el modelo OSI, ¿qué capa es responsable del direccionamiento lógico (direccionamiento IP) y de seleccionar la mejor ruta para que los datos viajen a través de redes interconectadas?

Respuesta correcta: B. Capa de Red

Explicación: La Capa de Red (Capa 3) se encarga del enrutamiento de paquetes de datos mediante direcciones lógicas (direcciones IP) para mover los datos a través de múltiples segmentos de red.

Pregunta 2: ¿Cómo se denomina comúnmente la Unidad de Datos de Protocolo (PDU) en la capa de Transporte (Capa 4) del modelo OSI, particularmente cuando se utiliza TCP o UDP?

Respuesta correcta: C. Segmento

Explicación: Los datos en la Capa de Transporte se dividen en Segmentos. La Capa de Red utiliza paquetes, y la Capa de Enlace de Datos utiliza tramas.

Pregunta 3: ¿Cuál de las siguientes es una función que realiza TCP (Protocolo de Control de Transmisión) en la Capa de Transporte y que no realiza su contraparte, UDP (Protocolo de Datagramas de Usuario)?

Respuesta correcta: B. Control de flujo y prevención de congestión.

Explicación: Tanto TCP como UDP utilizan números de puerto para la multiplexación (A). La fragmentación y el reensamblaje son gestionados por la capa IP o por la capa de aplicación (C). El control de flujo (que garantiza que el emisor no sature al receptor) y la prevención de congestión (que gestiona el tráfico de red) son características esenciales que hacen de TCP un protocolo confiable y orientado a la conexión. UDP no está orientado a la conexión y no ofrece ninguno de estos mecanismos.
