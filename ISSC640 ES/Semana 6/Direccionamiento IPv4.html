Direccionamiento IPv4

El direccionamiento IPv4 es la función principal de IP en Internet y en casi todas las redes en la actualidad. Una dirección IP es única para cada dispositivo conectado a Internet. Existen diferentes tipos de direcciones IP según la naturaleza del entorno de red donde se encuentra el equipo host. Una dirección IP tiene 32 bits de longitud, por lo que existen aproximadamente cuatro mil millones de direcciones posibles. Internet está quedándose sin direcciones IPv4.

La creación de direcciones IP privadas para IPv4 fue una solución crítica y de emergencia formalizada en 1996 por el Grupo de Trabajo de Ingeniería de Internet (IETF) en el RFC 1918.

La motivación principal fue conservar el suministro cada vez más reducido de direcciones IPv4 públicas únicas a nivel global, permitiendo que las direcciones no enrutables se utilizaran repetidamente en millones de redes privadas separadas (como hogares y oficinas). Hasta ese momento, si se deseaba que los equipos se comunicaran a través de Internet, era necesario asignar una dirección IPv4 pública a cada equipo de la red. Esto aceleró la presión sobre el suministro de direcciones IPv4. Se eligieron las direcciones no enrutables, denominadas direcciones IP privadas, y se comenzaron a utilizar en las LAN. A partir de entonces fue posible elegir una única dirección IP pública para acceder a Internet, la cual era compartida entre todos los equipos de la red. Este proceso se denominó Traducción de Direcciones de Red (NAT).
