Stakeholder Analysis

A matrix to estimate stakeholder support is useful to manage your stakeholders. Here is a simple matrix to capture this information:

A table showing a stakeholder analysis matrix with five columns labeled: Strongly Against, Moderately Against, Neutral, Moderately Supportive, and Strongly Supportive. Rows list stakeholders named Potter, Snape, and Weasley.

Legend:

  • An “X” marks each stakeholder’s estimated current position.
  • A “0” marks the desired position.

Stakeholder Positions:

  • Potter: Currently strongly supportive. Marked with both an X and a 0 in that column.
  • Snape: Marked as “Strongly Against” with an X and “Neutral” with a 0.
  • Weasley: Marked as “Moderately Against” with an X and “Neutral” with a 0.

A note below the table explains that X represents the estimate of the stakeholder’s current position and 0 represents the needed position.
